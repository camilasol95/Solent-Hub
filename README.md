# Solent Hub

Projeto React + Vite para visualizar os módulos do Solent Hub no Lovable ou em ambiente local.

## Como abrir no Lovable

1. Importe este repositório no Lovable.
2. Use o comando de desenvolvimento padrão:

   ```bash
   npm run dev
   ```

3. A aplicação sobe em `0.0.0.0:8080`, que é o host/porta configurado para preview.

## Scripts disponíveis

- `npm run dev` inicia o Vite para desenvolvimento.
- `npm run start` é um alias compatível com plataformas que procuram um script `start`.
- `npm run build` valida TypeScript e gera o build de produção.
- `npm run lint` executa o ESLint.
